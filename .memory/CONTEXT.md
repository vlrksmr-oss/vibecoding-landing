# Контекст проекта

## Рабочее пространство

- Назначение: лендинг подписки для ознакомления с курсом по вайбкодингу.
- Основной файл: `index.html`; одностраничная адаптивная реализация без сборки и сторонних зависимостей.
- Лендинг ведёт в канал MAX после настройки ссылки; автоматически не проверяет подписку и не выдаёт доступ.

## Подтверждённые технологии и версии

- Git: установлен; локальный репозиторий использует ветку `main`.
- HTML, CSS и JavaScript в одном статическом файле; внешние пакеты не используются.

## Постоянные технические ограничения

- Не добавлять сборщик или зависимости без необходимости.
- Хранить реальные секреты вне рабочего пространства; не копировать их в проект.
- Не подключать внешние сервисы и не публиковать проект без отдельного подтверждения.
- Локальная история Git не является внешней резервной копией.

## Важные файлы и расположения

- Правила агента: `AGENTS.md`.
- Инструкции Copilot: `.github/copilot-instructions.md`.
- Техническая документация: `docs/TECHNICAL.md`.
- Страница подписки: `index.html`.
- Память: `.memory/`.
- Путь к внешнему каталогу секретов хранится только локально в исключённом файле `.local/paths.json`.
- Абсолютный путь к секретам намеренно не записывается в отслеживаемые файлы.
