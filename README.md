# Рабочее пространство

Это пустая техническая основа для последующей разработки с ИИ-агентом. Здесь намеренно нет приложения, исходников, тестов и зависимостей: язык, фреймворк, архитектура и требования пока не определены.

## Начало работы

Перед новой задачей прочитайте `AGENTS.md` и файлы памяти в `.memory/`. При необходимости сверяйтесь с `docs/TECHNICAL.md` и `.memory/DECISIONS.md`. После существенного этапа обновляйте актуальные документы памяти и фиксируйте проверенную работу локально.

Реальные секреты храните только во внешнем каталоге, указанном в локальном, исключённом из Git файле `.local/paths.json`. Не помещайте секреты в проект, переписку, журналы или память. `.env.example` предназначен только для имён будущих параметров и безопасных примеров.

## Структура

- `AGENTS.md` — постоянные правила для агента.
- `.github/copilot-instructions.md` — краткая точка входа для Copilot.
- `.memory/` — технический контекст, состояние, задачи и журнал решений.
- `docs/TECHNICAL.md` — проверенные технические инструкции и команды.
- `.local/` — локальные служебные данные, полностью исключённые из Git.

После появления конкретного задания структуру и правила можно расширить с учётом подтверждённых технологий. Не добавляйте демонстрационное приложение или зависимости без необходимости.

## Фраза для нового чата

«Прочитай AGENTS.md и файлы памяти проекта. Восстанови технический контекст и продолжи работу по моему следующему заданию»
