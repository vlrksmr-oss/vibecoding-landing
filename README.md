# Страница подписки на курс по вайбкодингу

Одностраничный адаптивный лендинг на HTML, CSS и JavaScript без сборки и внешних зависимостей. Страница рассказывает о 7-дневном ознакомительном доступе к курсу, материалах по вайбкодингу, подарочной инструкции по созданию канала MAX и условиях перепродажи.

## Начало работы

Откройте `index.html` в браузере или разместите его на статическом хостинге. Перед публикацией замените пустое значение `MAX_CHANNEL_URL` в конце файла на публичную ссылку вашего канала MAX. Сейчас кнопки показывают уведомление, а не ведут на произвольную страницу.

Доступ к курсу и инструкцию по созданию канала необходимо выдавать через канал MAX согласно фактическим условиям организатора. Лендинг не собирает персональные данные, не проверяет подписку и не обещает доход.

## Структура

- `index.html` — вся страница, стили и интерактивные элементы.
- `.memory/` и `docs/` — рабочий контекст, статус и технические инструкции проекта.
