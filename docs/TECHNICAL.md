# Технические инструкции

## Git

- Репозиторий проекта локальный, основная ветка — `main`.
- Удалённые репозитории и push не настраиваются.
- Проверить состояние: `git status --short --branch`.
- Проверить исключение файла: `git check-ignore -v <путь>`.
- Проверить состав коммита: `git diff --cached --name-status`.
- `bootstrap-v1` обозначает техническую основу, а не версию продукта.
- На момент инициализации использованы уже настроенные глобально имя автора и email; учебные значения `Student` / `student@local.invalid` не потребовались.

## Секреты

- На Windows каталог находится в пользовательском `%LOCALAPPDATA%\LearningProjectSecrets\`; внутри него создаётся каталог проекта с коротким хешем пути.
- Абсолютный путь текущего проекта хранится в локальном `.local/paths.json`, исключённом из Git.
- Внешний каталог не является зашифрованным. Доступ ограничивается средствами Windows только для созданного каталога, если это поддерживается системой.
- Не помещайте реальные значения в `.env.example`, проект, память, журналы или переписку.
